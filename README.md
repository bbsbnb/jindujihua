# 市政道路工程进度计划 Agent

这是一个面向项目计划工程师的本地 MVP，覆盖标准 Excel 与普通进度表自动识别、数据校验、CPM 排程、周度滚动预测、资源/工作面冲突、纠偏情景、版本审批、字段级追溯，以及 Excel/PDF 导出。

## 快速开始

1. 创建虚拟环境并安装依赖：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. 双击 `run.ps1`，或在 PowerShell 中执行：

   ```powershell
   .\run.ps1
   ```

3. 浏览器打开 `http://127.0.0.1:8765`。
4. 下载标准模板，或直接上传已有 `.xlsx` 进度表。
5. 检查自动识别结果、问题清单、计划、关键线路和偏差。
6. 普通进度表的自动映射和补充内容经计划工程师确认后，可提交复核并由项目经理批准。

默认服务只监听本机地址。首次运行会在 `data/` 下创建 SQLite 数据库，并在 `generated/` 下保存每次运行的输入快照和交付物。

普通进度表无需预先改造成标准模板。系统会扫描工作表和表头，识别任务/WBS、计划起止、工期、完成率、实际日期及前置任务等常见字段，并生成不可签发的分析草案。自动映射、默认日历和补充值会进入问题清单，必须人工确认；系统不会凭空补造企业资源定额。

导航中的删除操作采用可审计归档：计划及其同名历史版本会从导航移除，但输入快照、交付物和审计记录不会被物理删除。

## Python 依赖

- Python 3.11+
- `openpyxl>=3.1`
- `reportlab>=4.0`

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## 交付边界

- 日期、工期、关键线路、偏差和情景模拟由确定性规则计算，语言模型不参与数值计算。
- 内置“对话助手”用于查询当前运行结果、解释问题和列出待办；生产环境可在同一接口后接入企业批准的模型服务。
- 当前为单项目、单日历、标准 Excel 首期版本，不直接连接 MSP、P6、ERP。
- 合规云部署所需的身份认证、对象存储、密钥管理和企业日志平台取决于目标云环境，不包含在本地 MVP 中。

```powershell
python -m unittest discover -s tests -v
```
